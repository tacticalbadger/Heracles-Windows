- The first native build of Heracles for Windows. It replaces the earlier Electron app (0.1.0) and does what the Mac app does.
- Notebooks, sections and pages in a sidebar, with favorites, archive, trash and search. Split panes with tabs, and any number of windows on the same library.
- A block editor: headings, lists, task lists, quotes, callouts, toggles, code blocks, images and columns, with Markdown as you type, a slash menu, and a handle on each block to move it or turn it into another kind.
- To-do lists are kanban boards. A card opens as a task with notes, a priority, dates, labels, a place, subtasks and comments.
- Reminders are delivered by Windows, whether or not Heracles is running.
- Import Markdown and HTML files; export a note as Markdown.
- A library from the earlier version is brought across the first time this one starts. The old library is not changed, and a copy of it is kept.
- An early build: it passes its automated tests, and nobody has used it day to day yet. Please report anything odd.
