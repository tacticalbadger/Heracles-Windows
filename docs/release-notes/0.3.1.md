- **An installer.** `Heracles-0.3.1-win-<arch>-setup.exe` installs Heracles for your Windows account without asking for an administrator, adds it to the Start menu, and can be removed again under **Settings ▸ Apps ▸ Installed apps**. A copy installed this way updates itself like any other, and Installed apps goes on showing the version it has reached. Removing it leaves your library where it is.
- **The disc image now holds the installer too**, beside the Heracles folder: run the installer from the disc, or copy the folder as before.
- Nothing in the app itself changed, and nothing changes for the copy you have: it updated itself to this version and stays in its folder. To move to an installed copy, close Heracles, run the installer, and delete the old folder. Your library is not in that folder and stays as it is.
